# Kimi K3 Together archive

This directory preserves the three original TogetherAI Kimi K3 trajectory
packages. The archived model key is `kimi-k3-together` and the display label is
`Kimi K3 Together`.

These files are intentionally outside `trajectory-viewer/data/runs/` and are
not referenced by the live manifest, main plot, grid plot, leaderboard, or
trajectory viewer. See `manifest.json` for the archived run inventory.
